# Word layout for Arinova tests

Use this only when the user asks for a Word (.docx) test instead of JSON, for example to print it. Arinova reads this layout when the file is uploaded under **Add material**. The same question standard applies: 4 options, 1 correct answer, an explanation.

- First line: the title in **Title** or **Heading** style, starting with the subject, e.g. `Verkeer toets 1 – voorrang`.
- Optional line under it with lesson and group: `Les 4 • Groep 7`.
- Questions numbered `1.`, `2.`, … each on its own line.
- The 4 options on their own lines below the question: `A. …`, `B. …`, `C. …`, `D. …`.
- At the end a heading **Antwoorden** (Turkish: **Cevaplar**, English: **Answers**), then one line per question: number, letter, explanation.

```text
Verkeer toets 1 – voorrang
Les 4 • Groep 7

1. Je fietst op een gelijkwaardig kruispunt. Wie heeft voorrang?
A. Verkeer van links
B. Verkeer van rechts
C. Wie het eerst bij het kruispunt is
D. Wie het hardst rijdt

2. Wat betekenen haaientanden op de weg voor jou?
A. Je mag als eerste doorrijden
B. Je moet hier parkeren
C. Je moet voorrang geven
D. Je rijdt op een fietspad

Antwoorden
1. B  Op een gelijkwaardig kruispunt geldt: verkeer van rechts gaat voor.
2. C  Haaientanden wijzen naar jou: dan moet je het verkeer op de andere weg voor laten gaan.
```
