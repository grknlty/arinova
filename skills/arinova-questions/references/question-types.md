# Cito question types

Examples from a Natuur en Techniek lesson (Thema 7.1 Puur natuur, Les 4 Nieuwe diersoorten: gewervelde en ongewervelde dieren indelen met een zoekkaart). Use the same shapes for other subjects and lessons.

## 1. Toepassen – classify a new case

> Dier X wordt gevonden in een vijver. Het heeft een ruggengraat, geen veren, legt eieren en heeft geen schubben. Welke indeling past volgens de leszoekkaart het best?
> A Amfibie · B Reptiel · C Zoogdier · D Geleedpotige

Wrong options are the groups one step away on the zoekkaart. Other subjects: a map situation (Topografie), a kruispunt (Verkeer), a source from a period (Geschiedenis), a sum in a story (Rekenen).

## 2. Waarneming of mening

> Mila schrijft: "Het dier heeft zes poten en twee voelsprieten. Daarom vind ik het eng." Welke zin is ALLEEN een waarneming?

Wrong options: an opinion, an assumption, a prediction. Variant: "Waarom is Sams uitspraak bruikbaarder voor een onderzoeksverslag?"

## 3. Gegevens lezen – data in the prompt

Write the data one item per block of lines, never as a `|` table (Arinova shows plain text; see "How it looks in Arinova" in SKILL.md):

```text
Drie onbekende dieren worden onderzocht.

Dier A
Ruggengraat: ja
Veren: ja

Dier B
Ruggengraat: nee
Uitwendig skelet: ja

Dier C
Ruggengraat: ja
Veren: nee
Eieren: nee

Welke combinatie past bij A, B en C?
```

Each wrong combination gets one or two items right, so the pupil must check all three.

## 4. Conclusie trekken – what is supported, what is ZEKER

> Dier A heeft een ruggengraat. Dier B heeft geen ruggengraat. Welke uitspraak kun je ZEKER doen, zonder meer eigenschappen te kennen?

Wrong options claim more than the data shows.

## 5. Redenering beoordelen – find the best counter-argument

> Een leerling noemt een zeester een vis, omdat beide in zee leven. Welk argument laat het duidelijkst zien dat die indeling niet klopt?

Wrong options are true but irrelevant (size, colour, speed). The right one uses the lesson's deciding feature.

## 6. Volgorde, eerste stap, ontbrekende informatie

> Een onderzoeker wil een onbekend dier met de zoekkaart indelen. Welke vraag moet hij als EERSTE stellen?

> Een biologe ziet een ruggengraat, maar geen veren. Ze weet nog niet of het eieren legt. Waarom kan zij het dier nog niet precies indelen?

Pitfall: for "what is still needed", the answer must be information the prompt does **not** already give.

## 7. Uitzondering op een regel

> Het vogelbekdier heeft een snavel, legt eieren en zoogt de jongen. Wat laat dit voorbeeld vooral zien?

Also: a bird that cannot fly, a vleermuis that flies but is a zoogdier.

## 8. Onderzoeksvraag of hypothese

> "Waarschijnlijk gebruikt hij zijn staart om vijanden af te schrikken." Wat is de BESTE onderzoeksvraag bij dit deel?

## 9. Waarom een kenmerk (niet) geschikt is

> Een klas begint haar zoekkaart met "Kan het dier zwemmen?" Waarom is dit minder geschikt dan "Heeft het dier een ruggengraat?"

## 10. Begrijpend lezen in de vakles

> "Hoewel het dier sterk op een vis lijkt, heeft het longen." Welke functie heeft "hoewel" hier?

Or: "Welke zin vat dit het best samen?" for a short quote from the lesson.

## 11. Bewijs kiezen

> Een leerling wil aantonen dat een dier een zoogdier is. Welk bewijs is het meest overtuigend?

## A balanced set of 30

| Type | Number |
| --- | --- |
| Toepassen | 6–8 |
| Gegevens lezen | 3–4 |
| Conclusie trekken / ZEKER | 3–4 |
| Redenering beoordelen | 3–4 |
| Waarneming of mening | 2–3 |
| Volgorde / ontbrekende info | 2–3 |
| Uitzondering | 1–2 |
| Onderzoeksvraag / bewijs / kenmerk | 2–3 |
| Begrijpend lezen | 1–2 |
| Plain recall | at most 6 |
